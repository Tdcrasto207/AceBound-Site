# AceBound — Website

Marketing site for AceBound (seller origination for boutique M&A advisors).

Single static page, no build step.

## Files

- `index.html` — the entire site (HTML + inline CSS)
- `netlify.toml` — tells Netlify to publish the repo root as-is

## Making changes

1. Edit `index.html`
2. Commit and push to `main`
3. Netlify rebuilds and deploys automatically

## Live site

Hosted on Netlify.
